Finance Tracker Design concepts v1 27 Jul 2026 Light mode

Six screens, one rule: logging beats reporting.

The visual language borrows from account statements rather than fintech dashboards — hairline rules, tabular figures, a single deep petrol accent doing all the emphasis, and colour reserved for categories where it actually carries meaning. Every screen is designed for one thumb. The phone frames below stay light in both page themes, because light mode is what's being reviewed.

Decisions this raises

Needs a verdict

Does the app icon open the overview or the numpad?

The proposal above assumes the icon opens the overview and the home screen widget goes straight to the numpad. That keeps the fast path fast while putting the budget in front of you daily — the thing every previous spreadsheet failed at. If the widget spike fails, this flips and the app should open straight to entry.

Needs a habit

How often do you update the balance figure?

With no bank feed, the projection is only as good as the balance you last typed in. Re-anchoring corrects all drift, so being a week stale is survivable — but a month stale makes the calendar screen fiction. A weekly nudge is the current plan.

Deliberate omission

Eight categories, and no subcategories on day one.

Every category you add is a decision at the moment of logging, which is exactly where friction kills the habit. Start narrow, and split a category only once the data shows one bucket is hiding something you actually want separated.
